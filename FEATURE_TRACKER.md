# Feature Tracker

Лёгкий трекер доработок проекта с кодами фич.

## Статусы
- `todo` — запланировано
- `in_progress` — в работе
- `done` — завершено
- `canceled` — отменено
- `blocked` — заблокировано

## Правила
1. Каждая новая доработка получает код `LGV2-XXX`.
2. Запросы сначала добавляются в `todo`.
3. Реализация и обсуждение ведутся по коду фичи.
4. При завершении статус переводится в `done` (с датой и ссылкой на коммит/PR).
